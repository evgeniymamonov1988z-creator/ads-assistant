КАК ЗАПУСТИТЬ НА WINDOWS (самый простой путь)

Шаг 1. Распакуйте архив adassistant.zip в папку, например C:\adassistant
        (правой кнопкой по архиву -> «Извлечь всё»).

Шаг 2. Установите Python, если его нет: python.org -> Downloads -> Python 3.11 или 3.12
        При установке ОБЯЗАТЕЛЬНО поставьте галочку «Add Python to PATH».

Шаг 3. Откройте папку adassistant\backend, щёлкните по адресной строке проводника,
        наберите cmd и нажмите Enter. Откроется чёрное окно.

Шаг 4. В чёрном окне выполните по очереди:

        python -m pip install -r requirements.txt

        (подождите, пока закончится установка)

Шаг 5. Запуск в демо-режиме (без реальных токенов, чтобы просто посмотреть):

        set MOCK_MODE=1
        python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Шаг 6. Откройте в браузере: http://127.0.0.1:8000
        Готово. Окно cmd закрывать нельзя — это и есть работающее приложение.

Шаг 7. Когда надоест смотреть демо: в окне cmd нажмите Ctrl+C, затем запустите
        без демо-режима:

        python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

        (переменная MOCK_MODE в новом окне уже не действует)

ДАЛЬШЕ: в браузере откройте вкладку «Токены» и впишите токены Директа, Google Ads,
номер счётчика Метрики и путь к журналу сервера. Нажмите «Проверить подключение».

ЕСЛИ ОШИБКА «python не является внутренней командой» — Python не добавлен в PATH.
Переустановите его с галочкой «Add Python to PATH».

ЕСЛИ порт 8000 занят — замените 8000 на 8010 и откройте http://127.0.0.1:8010
